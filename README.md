# IKEA-BILRESA-E2489---Zigbee2MQTT-Light-Control
Contrôle complet d'une télécommande IKEA BILRESA E2489 via Zigbee2MQTT. ON/OFF, double appui avec changement de couleur et variation cyclique de la luminosité et de la température de couleur.


Necessite la création d'un helper de type imput_select avec comme valeur:
- Blanc 
- Rouge 
- Vert 
- Bleu 
- Violet
